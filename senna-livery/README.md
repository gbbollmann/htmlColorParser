# Carta x Senna tribute livery

A McLaren MP4/4 inspired (Marlboro-era red/white) livery for the Carta Car Customizer car,
rendered through the same composite pipeline the customizer's "Export PNG" button uses:
background, floor shadow, base car photo, livery SVG multiplied through the body mask, then
overlay stickers.

- `carta-senna-livery.png` – the final 3068x1088 export.
- `index.html` – standalone page with the livery SVG and the export composite (open in a browser).
- `render.cjs` – headless Chromium render: `NODE_PATH=<path to node_modules with playwright> node render.cjs`.
- `assets/` – the base car and body mask extracted from the original bundled customizer HTML.

Livery notes: red (#E1251B) nose and rear with the forward-pointing chevron split, white door band,
carbon-black roof and sills, Carta logo in black on the white door band,
Senna's 1988 number 12 in red with a white keyline, and a Brazilian flag door sticker.

## 3D showroom (`3d/`)

An interactive three.js model built from the 2D render: the car's own silhouette is traced from the
base image (`build_3d_data.py`), split into a lower body and a narrower greenhouse, extruded with
rounded edges, wheel wells cut out, and textured by projecting the livery render onto every surface.
Lettering on the far side uses a second render with text mirrored in place, so it reads correctly from
both sides. Open `3d/index.html` over HTTP (ES modules), drag to rotate, scroll or pinch to zoom.

- `3d/index.html` – the viewer.
- `3d/car-outline.json`, `3d/body-texture*.jpg`, `3d/wheel.png` – generated by `build_3d_data.py`.
- `3d/screenshot.cjs` – headless render of five camera angles for checking changes.
- `3d/vendor/three.module.min.js` – three.js r160 (MIT), vendored so the page is self-contained.
